## Humanity impact

Topological Data Analysis (TDA) extracts **shape** that survives noise, coordinate choice, and nonlinear embedding — properties that coordinates alone miss:

| Domain | What Chrysalis enables |
|--------|------------------------|
| **Structural biology** | Conformation ensembles as point clouds; long $H_1$/$H_2$ bars flag cavities, tunnels, and binding-pocket topology relevant to drug design |
| **Oncology / medical imaging** | Tumor-margin and vessel point clouds; Betti curves track invasion fronts and microvascular loops without brittle segmentation heuristics |
| **Neuroscience** | Neural population manifolds; persistent $H_1$ detects cyclic coding (head-direction, grid modules) from spike embeddings |
| **Materials & soft matter** | Pore networks and phase-separated morphologies quantified by barcode statistics rather than single length scales |
| **Privacy-preserving shape** | Topology summaries are coarse invariants — share barcodes instead of raw identifiable geometry |

This repository is a **pure-Python, dependency-light** reference implementation of the classical persistence algorithm so researchers can audit every matrix step, teach the math, and prototype oracles before scaling to optimized C++ backends (Ripser, Gudhi).

## Theoretical foundations

### Vietoris–Rips filtration

Given a finite metric space $(X,d)$ and scale $\varepsilon \ge 0$, the **Vietoris–Rips complex** is the abstract simplicial complex

$$
\mathrm{VR}_\varepsilon(X) = \Big\{ \sigma \subseteq X \ \Big|\ \mathrm{diam}(\sigma) \le \varepsilon \Big\},
$$

where $\mathrm{diam}(\sigma) = \max_{x,y \in \sigma} d(x,y)$. As $\varepsilon$ grows one obtains a nested filtration

$$
\mathrm{VR}_{\varepsilon_0}(X) \subseteq \mathrm{VR}_{\varepsilon_1}(X) \subseteq \cdots \subseteq \mathrm{VR}_{\varepsilon_m}(X).
$$

The filtration value of a simplex $\sigma$ is exactly its diameter (for $0$-simplices: $0$).

### Chain complex and boundary operator

For each dimension $k$, let $C_k$ be the $\mathbb{F}_2$-vector space generated by $k$-simplices. The boundary operator $\partial_k : C_k \to C_{k-1}$ is

$$
\partial_k [v_0,\ldots,v_k] = \sum_{i=0}^{k} [v_0,\ldots,\hat{v}_i,\ldots,v_k] \pmod{2}.
$$

Homology is $H_k = \ker \partial_k \big/ \mathrm{im}\,\partial_{k+1}$. **Persistent homology** tracks how classes in $H_k$ are born and die along the filtration.

### Standard reduction algorithm

Order all simplices $\sigma_1,\ldots,\sigma_m$ by nondecreasing filtration value (break ties by dimension, then lexicographic vertices). Form the $m\times m$ boundary matrix $D$ over $\mathbb{F}_2$ with

$$
D_{i,j} = 1 \iff \sigma_i \subset \sigma_j,\ \dim\sigma_j = \dim\sigma_i + 1.
$$

Reduce columns left-to-right: while column $j$ and an earlier column share the same lowest $1$, add that column into $j$ (GF(2)). After reduction:

- a pivot at $(i,j)$ pairs **birth** $\sigma_i$ with **death** $\sigma_j$ → finite bar $[f(\sigma_i),\, f(\sigma_j))$;
- a fully zero column that is never a pivot birth is an **essential** class $\to$ bar $[f(\sigma),\, +\infty)$.

### Betti numbers along the filtration

$$
\beta_k(\varepsilon) = \#\big\{ \text{intervals in dim } k \text{ containing } \varepsilon \big\},
$$

with half-open convention $[b,d)$. The Euler characteristic is the alternating sum

$$
\chi(\varepsilon) = \sum_{k\ge 0} (-1)^k \beta_k(\varepsilon).
$$

### Complexity

| Stage | Time | Space |
|-------|------|-------|
| Distance matrix | $O(n^2 d)$ | $O(n^2)$ |
| Enumerate simplices up to dim $\Delta$ | $O\big(\sum_{k=0}^{\Delta}\binom{n}{k+1}\big)$ | same |
| Boundary reduction | $O(m^3)$ worst-case dense GF(2) ops ($m=\#$simplices) | $O(m^2)$ dense / $O(m\cdot\bar{s})$ sparse |

Practical regime: $n \lesssim 80$ at $\Delta\le 2$, or smaller $n$ for $\Delta=3$. This matches educational / oracle use; production TDA uses clearing + cohomology shortcuts.

## Quickstart

```python
import numpy as np
from chrysalis import circle_cloud, compute_persistence, betti_at_scale

pts = circle_cloud(36, noise=0.02, seed=0)
diagram = compute_persistence(pts, max_dim=1, min_persistence=0.05)
print(diagram.summary())

# Betti snapshot at a mid scale
beta = betti_at_scale(diagram, eps=0.8, max_dim=1)
print(beta)  # e.g. {0: 1, 1: 1}
```
